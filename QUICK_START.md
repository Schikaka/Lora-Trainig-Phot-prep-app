# 🚀 Quick Start Guide - LoRA Image Processor v1.4.0

## ⚡ Super Simple 4-Step Process

### Step 1: Install Requirements
```bash
pip install pillow opencv-python numpy
```

### Step 2: Prepare Your Photos
1. Create a ZIP file of your photos
2. Name it: `input.zip`
3. Put it in the `input/` folder

### Step 3: Run the Script
```bash
python lora_image_processor_standalone.py
```

### Step 4: Answer 2 Questions
1. **Size:** Press `1` (or just Enter) for 512x512
2. **Keyword:** Type your name (e.g., "Melodija")

### Done! 🎉
Your renamed files are in the `output/` folder!

---

## 📋 What You Get:

- ✅ Files named: YourKeyword_001.png, YourKeyword_002.png, etc.
- ✅ ONE file per photo (not duplicates)
- ✅ All same resolution (512x512)
- ✅ Face-detected smart cropping
