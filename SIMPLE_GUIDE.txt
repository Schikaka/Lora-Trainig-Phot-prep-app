================================================================
  LORA IMAGE PROCESSOR - SUPER SIMPLE GUIDE
================================================================

Follow these steps EXACTLY. Copy and paste commands.

================================================================
  STEP 1: DOWNLOAD THE ZIP FILE
================================================================

Click this link in your browser:

https://lora-smart-crop.preview.emergentagent.com/api/files/download/lora_image_processor_v1.0.0.zip

Save it to your Desktop.

================================================================
  STEP 2: EXTRACT THE ZIP FILE
================================================================

Windows:
  1. Right-click on lora_image_processor_v1.0.0.zip
  2. Click "Extract All"
  3. Click "Extract"
  
Mac:
  1. Double-click on lora_image_processor_v1.0.0.zip
  2. Wait for it to extract

You now have a folder called "lora_release" on your Desktop.

================================================================
  STEP 3: INSTALL PYTHON
================================================================

Windows:
  1. Go to: https://www.python.org/downloads/
  2. Click the BIG YELLOW button "Download Python"
  3. Run the installer
  4. CHECK THE BOX: "Add Python to PATH" (IMPORTANT!)
  5. Click "Install Now"
  6. Wait for it to finish
  7. Close the installer

Mac:
  1. Open Terminal (Cmd + Space, type "Terminal")
  2. Copy and paste this line, press Enter:
  
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  3. Wait for it to finish
  4. Copy and paste this line, press Enter:
  
brew install python3

  5. Wait for it to finish

================================================================
  STEP 4: INSTALL REQUIRED TOOLS
================================================================

Windows:
  1. Press Windows Key + R
  2. Type: cmd
  3. Press Enter
  4. Copy and paste this line, press Enter:
  
cd Desktop\lora_release

  5. Copy and paste this line, press Enter:
  
pip install pillow opencv-python numpy

  6. Wait 1-2 minutes for installation
  7. You'll see "Successfully installed..."
  8. Close the window

Mac:
  1. Open Terminal (Cmd + Space, type "Terminal")
  2. Copy and paste this line, press Enter:
  
cd Desktop/lora_release

  3. Copy and paste this line, press Enter:
  
pip3 install pillow opencv-python numpy

  4. Wait 1-2 minutes for installation
  5. You'll see "Successfully installed..."
  6. Close Terminal

================================================================
  STEP 5: TEST IT WORKS
================================================================

Windows:
  1. Press Windows Key + R
  2. Type: cmd
  3. Press Enter
  4. Copy and paste this line, press Enter:
  
cd Desktop\lora_release

  5. Copy and paste this line, press Enter:
  
python check_setup.py

  6. You should see: "ALL CHECKS PASSED!"
  7. If you see errors, go to TROUBLESHOOTING section below

Mac:
  1. Open Terminal
  2. Copy and paste this line, press Enter:
  
cd Desktop/lora_release

  3. Copy and paste this line, press Enter:
  
python3 check_setup.py

  4. You should see: "ALL CHECKS PASSED!"
  5. If you see errors, go to TROUBLESHOOTING section below

================================================================
  STEP 6: USE THE TOOL
================================================================

EVERY TIME you want to process images:

Windows:
  1. Put your photos in a ZIP file
  2. Name it: input.zip
  3. Move input.zip to Desktop\lora_release folder
  4. Double-click: run_windows.bat
  5. Wait for it to finish
  6. Find your processed images in: output.zip

Mac:
  1. Put your photos in a ZIP file
  2. Name it: input.zip
  3. Move input.zip to Desktop/lora_release folder
  4. Double-click: run_mac_linux.sh
  5. Wait for it to finish
  6. Find your processed images in: output.zip

OR use command line:

Windows:
  1. Open cmd (Windows Key + R, type cmd, Enter)
  2. Copy and paste:
  
cd Desktop\lora_release

  3. Copy and paste (replace YOURFILE.zip with your actual file):
  
python lora_image_processor_standalone.py YOURFILE.zip

Mac:
  1. Open Terminal
  2. Copy and paste:
  
cd Desktop/lora_release

  3. Copy and paste (replace YOURFILE.zip with your actual file):
  
python3 lora_image_processor_standalone.py YOURFILE.zip

================================================================
  TROUBLESHOOTING
================================================================

Problem: "python is not recognized"
Solution (Windows):
  1. Uninstall Python
  2. Download again from python.org
  3. Install again
  4. THIS TIME CHECK "Add Python to PATH" box!
  5. Restart computer
  6. Try again from STEP 4

Problem: "command not found: python3" (Mac)
Solution:
  Try using "python" instead of "python3" in all commands

Problem: "No module named 'cv2'"
Solution:
  Copy and paste this:
  
Windows:
pip install pillow opencv-python numpy

Mac:
pip3 install pillow opencv-python numpy

Problem: check_setup.py says something is missing
Solution:
  Run the install command again:
  
Windows:
pip install pillow opencv-python numpy

Mac:
pip3 install pillow opencv-python numpy

Problem: "No such file or directory"
Solution:
  Make sure you're in the right folder:
  
Windows:
cd Desktop\lora_release

Mac:
cd Desktop/lora_release

Problem: Double-clicking run_windows.bat does nothing
Solution:
  1. Right-click on run_windows.bat
  2. Click "Edit"
  3. Look at what it says
  4. Close it
  5. Open cmd (Windows Key + R, type cmd)
  6. Type the commands manually from STEP 6
