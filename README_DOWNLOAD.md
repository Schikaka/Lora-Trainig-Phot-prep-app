Prepares your photos for AI (Stable Diffusion LoRA) training by:
- ✅ Automatically cropping and centering faces
- ✅ Creating perfect 512×512 and 512×768 versions
- ✅ Filtering out blurry/poor quality images
- ✅ Analyzing your dataset variety

## 🚀 Quick Start (3 Steps)

### Windows Users:

**1. Install Python:**
- Go to: https://www.python.org/downloads/
- Download and install
- ✅ **CHECK "Add Python to PATH"**

**2. Install Dependencies:**
```
pip install pillow opencv-python numpy
```

**3. Use It:**
- Put photos in ZIP file named `input.zip`
- Double-click `run_windows.bat`
- Get `output.zip` with processed images!

### Mac/Linux Users:

**1. Install Python:**
```bash
brew install python3
```

**2. Install Dependencies:**
```bash
pip3 install pillow opencv-python numpy
```

**3. Use It:**
- Put photos in ZIP file named `input.zip`  
- Double-click `run_mac_linux.sh`
- Get `output.zip` with processed images!
