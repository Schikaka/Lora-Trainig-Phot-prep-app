SIZE OPTIONS EXPLAINED:

Both 512x512 and 512x768 (DEFAULT):
  → Creates 2 versions of each image
  → Best for complete training dataset
  → Recommended for most users

Only 512x512:
  → Square images
  → Perfect for close-up face training
  → SD1.5 compatible

Only 512x768:
  → Portrait images
  → Better for full-body shots
  → SD1.5 compatible

Only 1024x1024:
  → Large square images
  → Perfect for SDXL training
  → Higher quality but bigger files

================================================================

HOW TO CHOOSE SIZE:

For SD1.5 LoRA:
  → Use 512x512 or 512x768 (or both)

For SDXL LoRA:
  → Use 1024x1024

Not sure?
  → Use "both" (default)
  → You get both sizes and can choose later!

================================================================

INSTALLATION (ONE TIME):

1. Install Python (python.org)
2. Extract ZIP
3. Open folder in cmd/terminal
4. Run: pip install -r requirements.txt
5. Done!

================================================================

USAGE (EVERY TIME):

1. Put photos ZIP in input/ folder
2. Double-click run_windows.bat (or run_mac_linux.sh)
3. Choose size option (1-4)
4. Wait for processing
5. Get output from output/ folder

OR manual command:

python lora_image_processor_standalone.py input/photos.zip --sizes both
