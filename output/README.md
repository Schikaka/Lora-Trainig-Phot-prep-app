# Output Folder

Your processed images will appear here after running the script.

The script creates:
- A timestamped folder with all processed images
- A ZIP file of the processed images

Example:
```
output/
├── lora_processed_20251202_123456/
│   ├── MyKeyword_001.png
│   ├── MyKeyword_002.png
│   └── ...
└── lora_processed_20251202_123456.zip
```

Download the ZIP file for easy transfer to your LoRA training system!
