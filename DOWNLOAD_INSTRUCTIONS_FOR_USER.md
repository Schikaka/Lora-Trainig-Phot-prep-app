## 🚀 HOW TO USE:

### Step 1: Download
Click on `DOWNLOAD_THIS_FILE.zip` in the repository and download it.

### Step 2: Unzip
Extract the zip file. You'll get a folder called `lora_image_processor/`

### Step 3: Install Requirements
```bash
cd lora_image_processor
pip install -r requirements.txt
```

### Step 4: Run with Keyword Feature
```bash
python lora_image_processor_standalone.py input/your_photos.zip --keyword "MyDaughter"
```

**Your files will be renamed:**
- MyDaughter_001.png
- MyDaughter_002.png
- MyDaughter_003.png
- etc.
