=== HOW TO USE ===

**Interactive Mode:**
1. Keyword prompt: Enter "melodija"
2. Caption prompt: Enter "Melodija Girl, girl"  
3. Size prompt: Choose option
4. Processing creates .png + .txt for each image

**Command Line:**
```bash
python lora_image_processor_standalone.py \
  --keyword melodija \
  --caption "Melodija Girl, girl" \
  --sizes 512x512
```
