LoRA Image Processor
Version: 1.5.0
Release Date: December 3, 2025

=== NEW FEATURES in v1.5.0 ===

✅ **Advanced Facial Feature Detection**: Better face recognition!
   - Step 1: Tries to detect full face
   - Step 2: If no full face, looks for individual features (eyes, nose, mouth)
   - Step 3: If finds 2+ features (e.g., both eyes), crops around them
   - Step 4: Only if NO facial features at all, uses smart edge detection
   - "Interesting" = Facial features first, then edge detail
   - Much better at detecting partial faces, profiles, tilted heads

✅ **Smart Cropping (NOT center!)**: Finds the most interesting part
   - For photos WITHOUT faces: crops to the area with most detail/edges
   - NO longer always crops to center
   - Works great for food, scenery, objects when no face detected
   - Can crop to left, right, top, bottom - wherever the detail is!
   - Stays within image boundaries

✅ **Improved Face Detection**: Photos without faces go to rejections!
   - Photos WITH faces OR facial features → output/lora_processed_XXX/
   - Photos WITHOUT any facial features → rejections/
   - Blurry/dark photos → rejections/
   - Review rejections/ and move good ones to main folder if needed

✅ **Rejections Folder**: No files skipped anymore!
   - ALL images are now processed (even poor quality ones)
   - Nothing skipped - you decide what to keep
   - No more missing photos!

✅ **Skip Quality Check Option**: Full control
   - Use `--skip-quality-check` to process ALL photos to main folder
   - Or let the filter sort them for you

=== CRITICAL BUG FIXES in v1.4.2 ===

✅ FIXED: Duplicate files issue

✅ FIXED: File numbering is sequential
   - Files now numbered: 001, 002, 003 (no gaps or duplicates)
   - Counter increments once per input image

✅ FIXED: Output location
   - All processed files go to output/ folder
   - No longer creates output in input/ folder

✅ FIXED: Resolution prompts
   - Keyword prompt appears first
   - Resolution prompt appears second
   - Both prompts show correctly in interactive mode

✅ FIXED: Input file detection
   - Script automatically looks for input/input.zip
   - Default path works correctly
