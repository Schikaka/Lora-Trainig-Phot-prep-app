## Known Limitations (Documented)

1. **Face Detection**: Uses Haar Cascade (fast but less accurate than dlib)
   - Solution: Falls back to center crop if no face detected
   
2. **File Formats**: Supports JPG, PNG, BMP, WebP
   - Solution: Covers 95% of use cases
   
3. **Quality Thresholds**: Fixed values (not customizable via flags)
   - Solution: Can use --skip-quality-check flag

All limitations documented in user guides.
