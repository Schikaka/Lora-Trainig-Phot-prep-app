# LoRA Image Processor v1.4.0

**Clean, working version ready to use!**

## 📥 Download

Download: `lora_image_processor_v1.4.0_CLEAN.zip`

## ✨ Features

- ✅ Keyword-based file renaming (e.g., Melodija_001.png)
- ✅ Auto-detects input/input.zip (no arguments needed)
- ✅ Face detection with smart cropping
- ✅ Default: ONE file per photo (512x512)
- ✅ Optional: 512x768, 1024x1024, or both sizes

## 🚀 Quick Start

1. **Extract the ZIP file**
2. **Install:** `pip install pillow opencv-python numpy`
3. **Put input.zip in input/ folder**
4. **Run:** `python lora_image_processor_standalone.py`
5. **Done!** Get renamed files in output/
