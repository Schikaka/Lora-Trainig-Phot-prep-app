INSTALLATION ORDER:
1. Download all files → Put in one folder
2. Install Python 3.7+
3. Run: pip install -r requirements.txt
4. Run: python check_setup.py
5. Ready to use!

USAGE (Easy Method):
1. Put photos in ZIP file named "input.zip"
2. Double-click run_windows.bat (Windows)
   OR run_mac_linux.sh (Mac/Linux)
3. Get output.zip with processed images

USAGE (Command Line):
python lora_image_processor_standalone.py your_photos.zip
